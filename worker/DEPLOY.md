# Деплой Cloudflare Worker — пошагово

Это разовая настройка. После неё вкладка «План докупок» на сайте сможет
получать рекомендации от Claude по кнопке «Обновить рекомендацию».

Ключ Anthropic API нигде, кроме шага 5, вводить не нужно — он остаётся у
Cloudflare как секрет и не попадает ни в код, ни в git, ни ко мне.

## 1. Завести аккаунт Cloudflare (бесплатно)

Открой https://dash.cloudflare.com/sign-up и зарегистрируйся (email + пароль).
Платить не нужно — бесплатного тарифа Workers (100 000 запросов/день) с
запасом хватает для личного использования.

## 2. Поставить Node.js (если ещё не стоит)

Нужен только ради команды `npx` (запускает wrangler без долгой установки).
Скачать: https://nodejs.org — версия LTS. Проверить после установки:

```bash
node --version
```

## 3. Войти в Cloudflare через wrangler

Из папки `worker/` этого репозитория выполни:

```bash
cd worker
npx wrangler login
```

Откроется браузер — подтверди вход в свой аккаунт Cloudflare. После этого
терминал напишет что-то вроде «Successfully logged in».

## 4. Проверить, что имя Worker свободно

В файле `worker/wrangler.toml` уже задано имя `rebalance-worker`. Если при
деплое (шаг 6) окажется, что это имя занято (маловероятно, но бывает),
просто поменяй `name = "..."` в `wrangler.toml` на что-то своё, например
`name = "vlad-rebalance-worker"`, и повтори деплой.

## 5. Задать секрет — ключ Anthropic API

```bash
npx wrangler secret put ANTHROPIC_API_KEY
```

Терминал спросит значение — вставь свой ключ с
https://console.anthropic.com/settings/keys и нажми Enter. Ключ уйдёт
напрямую в Cloudflare, в терминале он не отображается и никуда не
сохраняется на диск.

Если ключа ещё нет — на той же странице console.anthropic.com можно создать
новый (нужен привязанный способ оплаты, т.к. это отдельный от Claude.ai
API-биллинг).

## 6. Задеплоить Worker

```bash
npx wrangler deploy
```

В конце вывода будет строка вида:

```
https://rebalance-worker.ТВОЙ-СУБДОМЕН.workers.dev
```

Это и есть адрес, который нужно вставить на сайте.

## 7. Указать адрес на сайте

Открой сайт → вкладка «План докупок» → поле «URL Cloudflare Worker» вверху
страницы → вставь скопированный адрес **без** `/api/rebalance-recommendation`
на конце (эндпоинт сам его добавит). Поле сохраняется в браузере
автоматически.

Нажми «Обновить рекомендацию» — если всё настроено верно, через пару секунд
появится текст рекомендации.

## Если что-то меняется в будущем

- **Поменял текст системного промпта или логику в `worker/index.js`** —
  из папки `worker/` снова `npx wrangler deploy`, адрес не меняется.
- **Нужно посмотреть логи Worker'а** (например, если сайт показывает ошибку) —
  `npx wrangler tail` покажет запросы в реальном времени.
- **Ключ Anthropic скомпрометирован/нужно обновить** — снова
  `npx wrangler secret put ANTHROPIC_API_KEY` с новым значением, перезаписывает
  старый.
